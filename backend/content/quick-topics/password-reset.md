# Password reset

**Password reset** covers your **Makerere** identity used on **portals**, **email**, and **SSO** systems.

**General steps:** On the **login page** of the system you need (ACMIS, MyPortal-linked app, webmail, etc.), use **Forgot password** or **Reset password** if available. Follow **verification** (email, SMS, or security questions)—**never post your password in chat**.

**Student portal password:** Use the **portal’s own** reset flow. If reset **email never arrives**, check **spam** and confirm you still have access to the **registered recovery address**.

**Locked account:** Multiple wrong attempts can **lock** sign-in temporarily. Wait for any **cool-off** period the screen states; if lock persists, **staff must unlock**—open **[Submit a support ticket](#support-ticket)**.

**When to use a support ticket in this app:** If **self-service reset fails**, **you are locked out** without recovery options, or **SSO rejects** a password you just set—open **[Submit a support ticket](#support-ticket)** so administrators can verify your identity through their process and email you when access is restored.
